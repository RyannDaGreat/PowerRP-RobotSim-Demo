# PowerRP RobotSim Demo

A PowerRP project stored as a plain GitHub repo instead of a zip.

**Open it:** https://ryanndagreat.github.io/SvelteLib/?repo=RyannDaGreat/PowerRP-RobotSim-Demo

## Layout

```
doc.json        the document
assets/         files it references, by relative name
```

That is the whole format — the same layout a PowerRP zip export uses, unzipped.
Edit `doc.json` here and the share link above serves the edit.
